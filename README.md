# Food-Waste-Prediction-Demand-Forecasting-and-Inventory-Optimization
This project provides a data-driven solution that forecasts food demand using historical sales, weather, event, and inventory data. The system helps reduce food waste by optimizing stock levels, generating reorder recommendations, and identifying surplus risks.

# Objectives
- Develop a data-driven system for food demand forecasting and food waste prediction.

- Improve food preparation planning using predictive analytics.
  
- Optimize inventory levels through automated recommendations.

- Reduce food waste and associated operational costs.

- Provide real-time decision support through an interactive dashboard.

- Promote sustainable and efficient food service operations.

# How It Works

**1. Data Validation**

Process raw food service data by handling missing values, removing duplicates, validating dates, and checking business rules.

**2. Feature Engineering**

Generate temporal features such as day, month, weekday, and weekend indicators.

**3. Demand Forecasting**

Use an XGBoost model to predict future food demand based on historical and environmental factors.

**4. Waste Prediction**

Use a Random Forest model to estimate expected food waste.

**5. Inventory Optimization**

Calculate safety stock, recommended inventory, procurement needs, waste percentage, and cost impact.

**6. Real-Time Predictions**

Serve predictions through a Flask API and display results via a Streamlit dashboard.

**7. Decision Support**

Provide inventory recommendations, waste-risk assessments, and potential cost-saving opportunities.
